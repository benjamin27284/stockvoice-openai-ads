**三个跨组的结构性发现（先讲，后面各段会反复用到）：**
1. **台股这一块：** campaign 投 TW+US，但语料四份档案中「台股／台积／0050」出现 **0 次**，网站的台股个股页也全空。只要 hint 写的是「一只股票」而没有锁在「美股」两个字之外的特征，台湾使用者问台股的对话在字面上就很像。这是**最大的一块误投面**。
2. **加密币这一块：** G06 和 G02 的 hint 点名 MSTR、COIN，这两档本身就是加密币的代理股（模拟 RC-016、RC-039、RC-080、RC-090 全在聊比特币）。所以 hint 的字面向「比特币／迷因币」敞开，但股声只接得住个股 MSTR、COIN，接不住币本身。
3. **限定条件太硬：** 「说出金额与期限」「会讲成本和现价」「AI 刚校正事实后」这类条件，在模拟里是作者写出来的；真实对话的第一轮多半很短，不会带数字。限定写得越硬，越会排掉真实流量里**最大量的那种短问句**（见 B）。

## C. 成效反推：投放系统在选什么（3 个可被数据验证的假设）

先把现象整理成三点（10/13 晚至今 9,200 曝光、99 点击）：
- A 版 6 则中 4 则 0 曝光；G06_A 只有 33 曝光、0 点击；G04_A 是唯一真正被投的 A（618 曝光，CTR 1.62%，6 组 12 则中最高）。
- G04_B 只有 230 曝光、CTR 0.43%，是 B 版最低。
- G06_B 的曝光是第二名 G01_B（2,573）的 1.7 倍。

### H1：A 版没被选，是因为文案和 hint 的语义对不上，不是因为「问句型」

- **推论：** 被投的 G04_A 也是问句（「赚了一倍，要不要先落袋？」），所以「问句被判为决定句」至少不是唯一原因。G04_A 和其他 A 的差别在于 Description **具体复述了 hint 描述的处境**：「一只股票快占账户一半，卖了又怕再涨」对上 hint 的「仓位越涨越重、占资产几成」。其他 A 的 Description 都是抽象的学习口吻（「学习梳理事件背景、信息来源与不同观点」「先区分整体市场与个别股票的变化」），和 hint 的处境词几乎没有重叠。
- **若成立，数据会长这样：**
  1. 拿 12 则文案的 Title 加 Description 和各自 hint 算词或语义重叠分，A 版曝光份额会随重叠分单调上升：G04_A 最高，G06_A（「群里、收益故事」有部分重叠，33 曝光）次之，其余 0。
  2. 把一则 0 曝光的 A（例如 G02_A）改写成复述处境（「成本 420 现在 380，睡不好？」这类，仍要守政策），新版应在 1–2 天内拿到曝光，而且不必改成产品名开头。
  3. 反过来，如果改写后仍然 0 曝光，H1 不成立，要看 H3。

### H2：B 版的「华语KOL／热度／社群讨论」把广告归到更宽的对话类别，所以 G06_B 曝光最多、CTR 偏低

- **推论：** G06_B 的 Description「整合华语KOL的市场观点与公开讨论，近24小时热度、多空理由一页看」是 12 则里**最不绑处境**的一则，任何「最近大家在聊什么股、币」的对话都对得上（A-G06-1、A-G06-3 的加密币和带单群都在内）。G06 的 hint 本身又点名 MSTR、COIN，加密币语境的对话量很大。
- **若成立，数据会长这样：**
  1. G06_B 的曝光对 G06 hint 的改动不敏感：把 hint 改窄（例如拿掉 MSTR、COIN），G06_B 的曝光降幅会很小；反之，把 B 的 Description 换成绑处境的句子，曝光会大降。
  2. G06_B 点击后的落地行为偏首页或热度榜：如果有 utm_content 或落地页分流，进个股页的比例低于 G01_B 和 G02_B；第二页浏览率和停留时间也比较低。
  3. 曝光时段会贴着加密币或迷因股的新闻高峰（比特币大涨日，G06_B 的曝光比其他组跳得更多）。
  4. TW 和 US 地区拆开看：如果 TW 占 G06_B 曝光的比例明显高于 TW 占全 campaign 的比例，就是在吃台股或加密币的对话。

### H3：clicks 目标下，投放系统是「先赢先拿」：早期哪一则先拿到点击，流量就锁给它。A 的 0 是分配问题，不是相关性问题

- **推论：** 新的广告组前几百次曝光在两则之间探索。产品名开头的 B 可能早期 CTR 稍高，于是被锁定；只有在 B 早期表现很差的组（G04_B 0.43%）A 才拿到份额，而 A 一拿到就表现最好（1.62%）。这代表 A 的真实 CTR 可能并不差，只是没被探索到。
- **若成立，数据会长这样：**
  1. 按小时看各组的曝光份额：上线头几小时 A、B 都有少量曝光，之后迅速倒向一边；G04 是倒向 A 的那组，而且倒向发生在 G04_B 累积几次 0 点击之后。
  2. 暂停某组的 B（例如 G02_B）24 小时，该组的 A 会接手大部分曝光，CTR 落在 B 的 ±0.5pp 以内。如果 A 接手后曝光量远低于 B 原本的量，就说明 A 仍被判为相关性低，回到 H1。
  3. 新建一个只含 A 的复制组，曝光量不会是 0。

**备注：** H1 与 H3 可以一次分开验证。做法是暂停 G02_B，同时把 G01_A 改写成复述处境：
- G02_A 原文拿到曝光 → 支持 H3（分配问题）；
- 只有改写过的 G01_A 拿到曝光 → 支持 H1（相关性问题）；
- 两者都拿到 → 两个机制并存。

H2 只需要看现有数据的地区拆分和落地页拆分，不必改投放。
