## g01_buy_after_rally（active）
Context hint：使用者在问一只已经大涨的美股现在还能不能买：股价创新高、连涨或财报后跳空，担心现在追会被套、买在山顶，后悔之前没买；会提到自己的成本、手上现金和打算放多久，问要不要分批、等回调还是先进一部分、跌了怎么办。常见于 NVDA、TSLA、META 这类大型科技股。
- SV_G01_A_CLICK_V5｜涨了这么多，是基本面还是情绪？｜怕错过，又怕追高？先了解上涨背后的原因、弄清楚这波涨的理由、市场的不同观点与风险，看清热度之外的依据。｜成效 0 曝光（系统没选它）
- SV_G01_B_CLICK_V5｜股声：追高前看各方当时怎么说｜追高前，先看华语KOL在类似高点说过什么，观点叠在真实走势上对照。｜成效 2,573 曝光 30 点击 CTR 1.17%

## g02_hold_or_cut（active）
Context hint：使用者手上的美股跌了或被套，在决定要撑、认赔、cut loss 还是攤平：会讲成本价和现价、亏了多少、这笔占账户几成，常说睡不好、不甘心、卖了又怕弹回去；有时是财报后跳空大跌或大盘急跌，问要不要先减一半、停损设在哪。常见于 TSLA、PLTR、META 这类波动大的持股；也包括 AI 解释板块重挫后，使用者说出自己持有那只、问要不要减。
- SV_G02_A_CLICK_V5｜被套之后，除了等回本还能怎么想？｜下跌消息很多，解释却不一样？学习梳理事件背景、信息来源与不同观点，分清事实和推测。｜成效 0 曝光
- SV_G02_B_CLICK_V5｜股声：被套时看看多空各几位｜被套时，先看华语KOL最近看多看空各几位、理由是什么，多空温度和走势一起看。｜成效 475/7 1.47%

## g04_take_profit（active）
Context hint：使用者的美股赚了很多，在想要不要落袋：赚了一倍、三倍，仓位越涨越重，目标价到了或财报前想锁住获利；会讲成本和现价、占资产几成、之后有没有要用钱，问要卖一半、卖到什么比例、stop loss 设在哪才能保住获利；常见是 NVDA、AVGO、PLTR 这类涨多的股票。
- SV_G04_A_CLICK_V5｜赚了一倍，要不要先落袋？｜一只股票快占账户一半，卖了又怕再涨。先定睡得着的比例，再决定卖多少。｜成效 618/10 1.62%（唯一被投的 A）
- SV_G04_B_CLICK_V5｜股声：落袋前看多空有没有变｜落袋前，先看华语KOL现在还看多的有几位、理由变了没，多空温度和走势一起看。｜成效 230/1 0.43%

## g06_everyone_talking（active）
Context hint：使用者看到身边都在聊某一只美股：群里、同事、家长群或网上大家都在买，说一个月赚了几成，自己还没买、怕错过，问现在上车会不会太晚、要投多少、能不能 all in；常见是 PLTR、MSTR、COIN 这类热门股或新题材。
- SV_G06_A_CLICK_V5｜群里都在买，他们看中了什么？｜群里的收益故事很吸引人？先看看大家关注它的理由与不同意见，分清讨论热度和信息依据。｜成效 33/0
- SV_G06_B_CLICK_V5｜股声：美股社群讨论热度看板｜整合华语KOL的市场观点与公开讨论，近24小时热度、多空理由一页看。｜成效 4,313/41 0.95%（曝光最多）

## g08_before_after_earnings（active）
Context hint：对话从有什么可以投、现在能不能进或财报季要注意什么开始，AI 提到财报季时程（金融股先、医药股后）并列出 JPM、LLY、MU 等名字后，使用者挑其中一只问：财报前先进场还是等财报出来、财报会不会大涨、财报当天怎么做，并说出打算投入的金额与期限。
- SV_G08_A_CLICK_V5｜财报前后，哪些信息不一样？｜期望值高时，好也可能跌。先想好要看哪几个财报数字，再看各方怎么解读。｜成效 0
- SV_G08_B_CLICK_V5｜股声：财报前后看各方怎么解读｜财报前后，先看华语KOL对这只怎么解读、多空温度有没有变，再对照真实走势。｜成效 77/1

## g10_market_panic_or_heat（active）
Context hint：对话从「美股是不是要崩了」「大跌我要怎么办」「现在是不是过热了」开始，AI 刚校正事实（指数其实只小跌、利率在高点、只有少数板块重挫）并给了框架后，使用者还没讲到具体个股，在问大盘会不会继续跌、要不要先走，或是不是只有自己这么慌；多半持有 SPY、QQQ、VOO 这类指数 ETF。
- SV_G10_A_CLICK_V5｜美股大跌，情况真有那么糟？｜大跌新闻让人担心？先区分整体市场与个别股票的变化，了解新闻背景与不同观点。｜成效 0
- SV_G10_B_CLICK_V5｜股声：慌的时候看SPY、QQQ多空｜大跌时，先看华语KOL对SPY、QQQ的看多看空人数，再对照真实走势。｜成效 881/9 1.02%

## 规则（不可违反）
- 意图不可从产品功能反推（使用者三次纠正）；要从「使用者在对话里讲自己的事／AI 刚做了什么→使用者接着问什么」出发。
- 文案政策：股声＝金融资讯整合非金融服务；禁交易动作词／报酬／煽动／预测／挑标的（见 memory openai-ads-financial-policy-rules）。本任务不写文案，只找意图。
- 语料：realchat/conversations.csv（90：60 种子＋30 野生）、realchat/holdout/conversations_holdout.csv（25）、realchat/trajectory/trajectories.csv（56 条多轮）、realchat/nonspecific/conversations_ns.csv（30 段，slot 级）、nonspecific/posts_sample_classified.csv（网站帖子样本）。所有语料都是我们自己写的模拟对话（不是真实 ChatGPT log），引用时要说「模拟」。
